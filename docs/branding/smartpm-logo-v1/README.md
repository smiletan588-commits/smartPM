# SmartPM Logo V1

设计方向：协作路径。三段水平笔画连接为S形路径，呼应任务阶段与协作推进。主色#315CF4，文字#172238。

- smartpm-icon.svg：透明背景独立图标。
- smartpm-logo.svg：浅色背景横向组合。
- smartpm-logo-white.svg：深色背景反白组合。
- preview.html / preview.png：设计预览，不是系统改版截图。

本版为用户同意的手工SVG方案，不使用AI生成位图。2026-09-27已接入系统：登录页、侧栏和移动端顶部共用BrandMark组件，浏览器标签使用同一图标（kanban-frontend/public/smartpm-icon.svg）。本目录保留设计提案及预览。SVG图形为路径，文字采用Segoe UI、Arial回退，尚未转曲；跨平台交付前需核对字形。图标建议至少24px，保留至少一个笔画宽度的外部留白。未进行商标相似性或注册可用性检索。
