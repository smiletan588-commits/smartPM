# SmartPM AI 效果评估指南

## 实验目标

使用 `ai-evaluation-dataset.json` 中 20 个不同类型的项目需求，对 AI 项目规划的可用性与系统稳定性进行可复现评估。每条需求至少运行一次，建议在相同模型、Prompt 版本与网络环境下重复 3 次。

## 操作步骤

1. 为每条数据创建独立项目，将 `requirement` 作为项目描述。
2. 调用“AI 生成项目计划”，记录是否解析成功、响应时间和生成任务数。系统会自动写入 `pm_ai_operation_log`。
3. 两名评价者独立按 1–5 分评价完整性、清晰度和可执行性，取平均值。
4. 根据真实决策点击“应用计划”，不应为提高采纳率而全部应用。应用后变更的任务数填入结果表。
5. 从数据大屏记录 AI 成功率、平均响应时间、采纳率、平均评分和 AI 生成任务占比。

## 指标定义

| 指标 | 计算方式 |
| --- | --- |
| 解析成功率 | 成功返回结构化计划次数 / 总调用次数 |
| 平均响应时间 | 所有调用的 `duration_ms` 算术平均值 |
| 采纳率 | 已应用 AI 结果次数 / 成功调用次数 |
| 评分 | 完整性、清晰度、可执行性各 1–5 分；系统内评分取总体感受 1–5 分 |
| AI 任务占比 | `ai_generated = 1` 的非回收站任务 / 全部非回收站任务 |

将原始值填入 `ai-evaluation-results-template.csv`。论文中至少输出场景分组统计表、指标总览表、响应时间柱状图和评分雷达图，并报告失败样例，不要只展示最优结果。
